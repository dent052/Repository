# 設計資料: 情報セキュリティマネジメント試験 学習システム

## 目的

情報セキュリティマネジメント試験（SG）に合格すること。
「体系的に学ぶ → 確認テストで定着を確かめる → 本番レベルの問題を解く」の順に進める仕組みにする。

## 対象とする試験（2026年度まで実施の現行制度）

| 項目 | 内容 |
| --- | --- |
| 方式 | CBT、通年実施 |
| 試験時間 | 120分（科目A・科目Bを通しで解答） |
| 科目A | 48問、四肢択一、知識問題 |
| 科目B | 12問、多肢選択、事例（ケーススタディ）問題 |
| 合格基準 | 総合評価点 1,000点満点中 600点以上 |

- 出題範囲は IPA のシラバス（Ver.4系）に沿う。
- 2027年度から試験制度の見直しが予定されている。新制度に切り替わったら本資料と問題を見直す。

## 出典について

- 問題・解説・学習テキストはすべて本リポジトリで書き起こしたオリジナルである。
- 過去問・サンプル問題の文章は転載しない。出題傾向（頻出テーマ、問われ方、難易度）だけを参考にする。

## 学習の流れ

```
[章1 学習] → [章1 確認テスト(80%以上で合格)] → [章2 学習] → … → [章10 確認テスト]
                                                                    ↓ 全章合格
                                            [分野別演習] [科目B演習] [弱点復習] [模擬試験]
```

1. **体系学習**: 章は 1 → 10 の順にしか開けない。前の章の確認テストに合格すると次の章が開く。
2. **確認テスト**: その章の問題からランダムに 5 問。4 問以上（80%以上）正解で合格。
3. **演習**: 全章の確認テストに合格すると開く。
   - 分野別演習: 章を選んで、その章の全問題をランダム順に解く。
   - 科目B演習: 科目B形式の事例問題をランダム順に解く。
   - 弱点復習: 「直近で間違えた問題」と「まだ2回連続で正解していない、一度でも間違えた問題」を解く。
   - 模擬試験: 科目A 48問 + 科目B 12問、制限時間120分。終了後に得点と章別の正答率を表示する。

## 章構成（シラバスとの対応）

| 章 | タイトル | 主なシラバス項目 |
| --- | --- | --- |
| 1 | 情報セキュリティの基本 | 情報資産、CIA・真正性・責任追跡性・否認防止・信頼性、脅威と脆弱性 |
| 2 | 脅威と攻撃手法 | マルウェア、標的型攻撃、ソーシャルエンジニアリング、パスワード攻撃、Web・ネットワーク攻撃 |
| 3 | 暗号と認証 | 共通鍵・公開鍵暗号、ハッシュ、デジタル署名、PKI、利用者認証、TLS |
| 4 | 技術的セキュリティ対策 | FW・WAF・IDS/IPS・DMZ、VPN、マルウェア対策、メール・無線LAN、ログ、脆弱性管理 |
| 5 | 情報セキュリティマネジメント | ISMS（JIS Q 27001/27002）、ポリシー体系、リスクアセスメント、リスク対応 |
| 6 | インシデント対応と組織 | CSIRT・SOC、インシデント対応手順、フォレンジクス、BCP、外部機関・評価基準 |
| 7 | 法務と標準・ガイドライン | サイバーセキュリティ基本法、不正アクセス禁止法、個人情報保護法、刑法、著作権、契約、ガイドライン |
| 8 | テクノロジの基礎 | ネットワーク、データベース、システム構成と可用性、バックアップ |
| 9 | マネジメント・ストラテジ | プロジェクト管理、サービスマネジメント、システム監査、内部統制、経営・調達 |
| 10 | 科目B対策 | 事例問題の解き方（章10の確認テストは科目B形式の問題から出す） |

## 採点

- 1問の配点は均等とし、`正解数 / 出題数 × 1000` を得点（目安）とする。600点以上を合格目安とする。
- 本番は IRT による採点で配点は非公開のため、あくまで目安である。

## 模擬試験の出題

- 科目A 48問を章1〜9から出す。各章の出題数は、その章の問題数に比例させる（端数は問題数の多い章から割り当てる）。
- 科目B 12問は科目B問題からランダムに出す。

## データ形式

問題（科目A・科目B共通）:

```js
{
  id: "a3-05",          // 一意。科目Aは "a<章>-<連番>"、科目Bは "b-<連番>"
  chapter: 3,           // 科目Bは 10
  scenario: "<p>…</p>", // 科目Bの事例文（HTML）。科目Aでは省略
  question: "…",        // 設問（HTML可）
  choices: ["…", "…"],  // 科目Aは4つ、科目Bは4〜10個
  answer: 0,            // 正解の choices の添字
  explanation: "…",     // 解説（HTML可）
}
```

章:

```js
{ id: 1, title: "…", goal: "…", body: "<h3>…</h3>…" }
```

## 進捗の保存

```js
{
  passed: { "1": true, … },                 // 確認テストに合格した章
  stats:  { "a3-05": { c: 2, w: 1, streak: 1, last: true } }, // 正解数・不正解数・連続正解数・直近の正誤
  exams:  [ { date: "2026-10-07T10:00:00.000Z", score: 650 } ]  // 模擬試験の記録（直近20回まで）
}
```

- まずブラウザの localStorage に保存する。
- claude.ai の Artifact として開いた場合は、`db` 機能が使えればログイン中の本人専用領域（`data/users/<id>/progress/main`）にも保存し、端末をまたいで進捗を引き継ぐ。
- db への書き込みは1件ずつ行い、書き込み中に発生した変更は次の1回にまとめる（同時書き込みをしない）。
- 演習・確認テストでは1問ごとに正誤を記録する。模擬試験は終了時にまとめて記録する。

## 構成

```
web/index.html        画面
web/app.js            画面制御（DOM 操作、保存）
web/core.js           純粋関数（ロック判定、採点、弱点抽出、模擬試験の組み立て）
web/data/chapters.js  学習テキスト
web/data/questions-a.js  科目A問題
web/data/questions-b.js  科目B問題
test/                 node:test によるテスト（ロジックとデータ整合性）
server.js             ローカル配信用の最小 HTTP サーバー
```
