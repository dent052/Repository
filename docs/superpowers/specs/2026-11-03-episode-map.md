## 方針

- **目標: 科目Aの過去問445問の全てについて、その論点をどこかの話の場面で教える。**
  - 同じ論点の問題は、話の中で1〜2問を本番の問題として出す。残りは取り返し問題と後始末（復習）で出す。
  - 過去問は年度をまたいで同じ問題が多いので、論点の数は過去問の数よりずっと少ない。
  - 全ての話を書き終えたら、この目標を `test/data.test.js` で確かめる（過去問の論点が、全てどこかの場面の `points` に入っている）。
  - 論点が `points` に入っていても、場面の説明で解けるとは限らない。場面だけで解けるかは、話ごとに Codex に答えを伏せて解かせて確かめる。
- **話の数を30から40に増やす**（`PLANNED_EPISODES = 40`）。30話のままだと、1話の論点を倍近くに増やすことになり、1話15分に収まらない。
- **第15話からは、各話の最後に科目Bの事例問題を1問出す。** 選ぶのは、その話で教えた論点で解ける問題。最後の2話は科目Bだけの総仕上げにする。60問・120分の通し演習は、今の模擬試験で行う。
- 順番: インシデント対応の続き → ネットワークの基礎 → 攻撃 → 防御 → 運用 → 法務 → マネジメント系 → テクノロジ系の残り → 科目Bの総仕上げ。ネットワークの基礎は、第21話以降の DNS・メールへの攻撃やファイアウォールの規則の前提になるので先に置く。
