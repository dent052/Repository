# SG 合格トレーナー

情報セキュリティマネジメント試験（SG）に合格するための学習システムです。
シラバスに沿った10章のテキストで体系的に学び、各章の確認テストに合格すると、本番レベルの演習と模擬試験（科目A 48問 + 科目B 12問 / 120分）に進めます。

## 使い方

Node.js 20 以上が必要です（外部パッケージは使いません）。

```sh
npm start      # http://localhost:8000 を開く
npm test       # ロジックと問題データのテスト
```

## 学習の進め方

1. 第1章から順にテキストを読み、確認テスト（5問中4問以上で合格）を受ける。
2. 全章に合格すると「演習」が開く。
3. 分野別演習・科目B演習で本番形式に慣れ、弱点復習で間違えた問題を潰す。
4. 模擬試験で 600点（目安）を安定して超えたら本番へ。

仕様の詳細は [docs/design.md](docs/design.md) を参照してください。
